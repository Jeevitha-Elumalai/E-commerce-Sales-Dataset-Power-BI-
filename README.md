
# 📊 Power BI Data Cleaning and Data Modelling Project

## 📌 Project Overview
This project focuses on data cleaning, transformation, data modelling, and analysis using Microsoft Power BI. The objective is to prepare raw datasets, establish relationships between tables, and create meaningful summary tables for business analysis.

## 🎯 Project Objectives
- Import and explore multiple datasets.
- Clean and transform raw data using Power Query Editor.
- Create calculated columns for business analysis.
- Handle missing values and duplicate records.
- Perform grouping and aggregation.
- Establish relationships between tables using Model View.
- Prepare structured data for meaningful analysis.

## 🗂️ Datasets Used
The project includes the following datasets:

1. **List of Orders**
2. **Order Details**
3. **Sales Target**

## 🛠️ Tools and Technologies
- Microsoft Power BI
- Power Query Editor
- DAX (Data Analysis Expressions)
- Data Modelling
- Data Transformation

## 🔄 Data Cleaning and Transformation

The following operations were performed using Power Query Editor:

1. **Imported Datasets** – Loaded the required datasets into Power BI.
2. **Row Limiting** – Applied row limits where required.
3. **Data Types** – Changed columns to appropriate data types.
4. **Proper Case Formatting** – Standardized text formatting.
5. **Location Column** – Created a location column for geographical analysis.
6. **Profit Margin** – Calculated profit margin for business analysis.
7. **Profit Status** – Created a conditional column to classify profit status.
8. **Merge Operation** – Combined relevant tables using matching columns.
9. **Missing Values and Duplicates** – Handled missing values and duplicate records.
10. **Sorting and Filtering** – Organized data and applied relevant filters.
11. **Grouping and Aggregation** – Created summary tables using Group By.
12. **Model View** – Established relationships between the datasets.

## 🔗 Data Modelling

Relationships were established between the following tables:

- **List of Orders and Order Details** – Connected using Order ID.
- **Order Details and Sales Target** – Connected using Category.

Data modelling helps connect related datasets and supports analysis across multiple tables.

## 📈 Data Aggregation

Created summary tables to perform the following calculations:

### Order Details Summary
- Count of Order ID
- Average Profit by Category
- Total Amount by Sub-Category

### Additional Summary Tables
- Profit Summary
- Total Amount Summary
- Sales Target Summary
